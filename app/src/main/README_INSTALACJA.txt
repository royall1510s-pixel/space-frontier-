# Kosmiczna Przygoda — V1 Home Screen

Wgrane zmiany:
- nowy ekran startowy HomeActivity,
- animowana gwiezdna przestrzeń,
- wieża startowa i własna rakieta rysowana w Canvas,
- przycisk START MISJI otwierający istniejący MainActivity,
- istniejący silnik gry pozostaje nietknięty,
- MainActivity przestaje być launcherem.

## Pliki
- app/src/main/java/com/kosmicznaprzygoda/app/HomeActivity.kt
- app/src/main/AndroidManifest.xml

## Instalacja
Skopiuj oba pliki do odpowiadających im ścieżek w repozytorium i uruchom GitHub Actions.
